# zhcipher：古风中文加密程序

流程：数字密钥 + 密码表（64～1024 字，建议 256 字，可有重复） + 原文 → 古风诗句密文；解密反过来。

## 构建
需要 C++17、CMake、libsodium（`apt install libsodium-dev` / `brew install libsodium`）。

    cmake -S . -B build && cmake --build build
    ./build/test_codec && ./build/test_crypto

## 使用
    ./build/zhcipher enc -c 密码表.txt            # 交互：数字密钥 → 原文
    ./build/zhcipher dec -c 密码表.txt --verify   # 交互：数字密钥 → 密文

不带 `-k`/`-c` 时按顺序交互输入：数字密钥 → 密码表 → 原文/密文（Ctrl-D 结束）。
数字密钥或密码表不对时，解密不报错，输出错误结果（无效字节显示为随机汉字）；加 `--verify` 才会在 stderr 告知校验结果。

## 设计
1. 数字密钥 --Argon2id--> 32 字节种子
2. 种子驱动确定性洗牌，把密码表里的字（含原始顺序）重新排列
3. 排列后的整张密码表 --BLAKE2b（以种子为密钥）--> 256 位密钥
4. 明文(UTF-8→GB18030) --ChaCha20(6 字节随机数)--> 随机数‖密文‖8 字节 BLAKE2b 标签（标签在解密时只用来判断对错，不对也照常输出）
5. 变长长度头 + 上述字节 → 位流 → 诗句（`src/lexicon.cpp` 顶部有槽位说明）

诗句编码器不用密钥，算法公开；安全性全在 1–4 步。每首诗 4 句，五言/七言由数据位决定，
每首诗选一个主题（秋景/月夜/山水/送别/春景/冬雪/田园/边塞）和一个韵部（共 8 个）；第 2、4 句押韵；暂不管平仄。

## 使用建议
- 数字密钥建议 16 位以上；密码表用随机汉字，别用名篇；允许有重复的字，但不重复的字太少（少于 64 个）会很弱。字的顺序也算密码表的一部分。
- 密文必须保留标点/换行断句，否则无法解码。
- 明文上限约 6 万字节。为缩短密文：原文先转 GB18030（汉字 2 字节）、随机数 6 字节、标签 8 字节、词池较大（每个诗字约带 4 位）。

## 菜单版「中西部山顶火车票」（推荐日常使用）
    bash zc.sh --install     # 第一次：创建 alias zc 和 Windows 桌面“中西部山顶火车票.bat”
    zc                       # 以后：输入 zc 回车，或双击桌面“中西部山顶火车票.bat”
菜单里可以加密、解密、生成随机密码表、检查密码表。
数字密钥和密码表都在窗口里输入（输入时不显示，可分多段粘贴），不保存到任何文件；
输入密码表时会显示"已输入多少字、其中不重复多少个"。
解密时输错数字密钥或密码表，菜单不会报错也不会提示，只输出一段看起来像中文的乱码。
